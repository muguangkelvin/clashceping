# 文章发布与服务更新规范指南 (Publishing Guide)

## 1. 新增文章规范
1. **文章位置**：普通文章存放在 `src/content/docs/` 或 Astro 对应数据模板中。
2. **字符数控制**：净中文正文字符数需严格控制在 800 至 1200 字之间（不含 Header/Footer/侧边栏与重复声明）。
3. **元数据必填项**：
   - `title`: 包含主关键词与吸引力副标题
   - `description`: 80-140字自然包含辅助词
   - `slug`: 简短英文 slug
   - `primaryKeyword`: 页面分配的唯一主关键词
   - `lastChecked`: 最新的数据核验日期
4. **固定四项推荐榜单**：除纯协议/故障排障文章外，所有推荐/比较文章均须按固定顺序引入四项主推服务：
   - 第一主推：灵动云
   - 第二主推：暮光网络
   - 第三主推：飞猫云
   - 第四主推：微风网络

## 2. 新增与更新服务商数据
1. 编辑 `src/data/providers.json` 数据源。
2. 修改价格、套餐、优惠码或 `lastChecked` 字段。
3. 运行 `npm run build` 执行自动化构建与 SEO 检查。
