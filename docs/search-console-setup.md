# Google Search Console & Bing Webmaster 接入指南

## 1. 域名与验证设置
1. 打开 Google Search Console，添加 Domain 属性 `clashceping.homes`。
2. 添加 DNS TXT 记录或 HTML 标签验证码。
3. 验证通过后，在 `https://clashceping.homes/sitemap-index.xml` 提交 Sitemap。

## 2. Bing Webmaster & IndexNow 快速收录
1. 在 Bing Webmaster Tools 中使用与 GSC 关联导入。
2. 提交站点 `sitemap-index.xml`。
3. 配置 IndexNow Key，每次部署更新后发送 URL 推送变更。
